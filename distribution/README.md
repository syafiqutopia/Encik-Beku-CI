# Distribution exports

Rendered from the `svg/` masters — never hand-produced, so they always match.

```bash
./tools/build-distribution.sh
```

## `encik-beku/`

| Family | Widths | Notes |
|---|---|---|
| `*-primary-{light,dark}` | 512 / 1024 / 2048 / 3840 | Square, transparent |
| `*-secondary-{light,dark}` | 512 / 1024 / 2048 / 3840 | 5:1, transparent |
| `*-single-{navy,white}` | 512 / 1024 / 2048 / 3840 | One ink, transparent |
| `*-mark-{light,navy,white}` | 256 / 512 / 1024 | Icon-only shield |
| `*-print.pdf` | 360pt / 504pt | **True vector**, zero raster objects |

All PNGs carry an alpha channel. Place them on their intended ground — the
`-dark` and `-white` variants are invisible on white.

## No WebP

Neither `sips` nor macOS ImageIO can encode WebP on the build machine, and this
kit does not ship a format it cannot verify. Serve the SVG to modern browsers
and these PNGs as the fallback; that combination already covers every target.

If WebP becomes necessary, add a real encoder (`cwebp` from libwebp) and extend
`tools/build-distribution.sh` — do not rename a PNG.

## Print PDFs

Generated by WebKit's PDF writer from the SVG masters, so they contain only the
logo — no hidden page furniture, no embedded rasters. Verified at 0 image
objects and crisp at 10× magnification.

Send these to print vendors who want PDF. Vendors who accept SVG should get the
SVG.
